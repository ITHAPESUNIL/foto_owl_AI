# Foto Owl - Real-Time Interactive Gallery

React Intern Assignment submission for Foto Owl.

## Features Built
- Real-time Multi-User Emoji Reactions
- Real-time Comments with timestamp & deletion support
- Global Live Interaction Activity Feed
- Unsplash API integration with curated fallback
- Persona / User Identity switcher (for multi-tab testing)

## Setup & Run
1. Unzip project
2. `npm install`
3. `npm run dev`
4. Open `http://localhost:5173` in multiple tabs.
